# ui-daily

每天由 Claude 雲端 routine 自動生成的 UI/UX 設計靈感。

- `style-library.md` — 57 種 UI 風格配方（挑方向用）
- `taste-log.md` — 韡寧的品味檔（她 ❤️ 過的，會影響之後生成）
- `reviews/<日期>/` — 每天生成的 6 個 UI + 一頁審查用畫廊 `index.html`
- 審查連結（未公開，用 raw.githack 渲染）：
  `https://raw.githack.com/weiwei0607/ui-daily/master/reviews/<日期>/index.html`
- 她 ❤️ 過的才會被放進對外作品集（之後再開）。❤️ 狀態存在 Firebase RTDB `/uigallery`。
